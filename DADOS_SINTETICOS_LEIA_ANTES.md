# ReViver — dados CSV para testes

Os arquivos CSV deste pacote contêm registros sintéticos para desenvolvimento e testes. Nomes, clínicas, contatos, datas e registros de atendimento são fictícios e não devem ser usados para atendimento real.

## Arquivos
- `usuarios.csv`: perfis de teste.
- `conversas.csv`: exemplos de perguntas e encaminhamentos.
- `clinicas.csv`: unidades e equipes fictícias.
- `substancias.csv`: textos educativos resumidos; não substituem avaliação profissional.
- `planilha_sem_titulo_pagina1.csv`: estrutura/dicionário de dados e campos de exemplo.
- `backend/impactojovem.csv - Página1.csv`: planilha de indicadores de teste.

Os CSVs foram salvos em UTF-8, com cabeçalhos preservados, e os arquivos mantêm pelo menos 1.000 linhas de dados. A planilha de estrutura teve colunas totalmente vazias removidas para facilitar a leitura no GitHub.
